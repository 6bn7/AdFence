AdFence 更新内容（倒序）

────────────────────────────
v2.7 —— 依据第三方安全审计报告修复
 · DNS 转发改用已连接(connect)的 socket，并校验事务 ID / 来源地址端口 / QR 位
   （消除"全设备 DNS 应答可被伪造成中间人投毒"的问题）
 · 转发移入线程池异步执行 + 64 并发上限背压；单上游超时 4s→1.5s
   （避免上游卡顿时整台设备 DNS 集体卡死）
 · 删除更保守：新增「清理前先问我」且默认开启；移除通用目录名规则；
   目录前缀匹配必须先发现广告 SDK 特征文件
 · 新增回收站：删除的非媒体文件先进 trash/，24 小时内可找回
 · DNS 日志改写入应用私有目录；默认只记被拦域名（全量记录需手动开启）
 · 移除"从外部存储加载拦截规则"的路径（规则注入面）
 · 留样/回收站文件名做净化 + 路径校验，防路径穿越与配额绕过
 · 规则集合改为并发安全；域名做字符白名单校验（防日志注入）
 · 丢弃含压缩指针或多问题段的畸形查询；统计表加上限
 · 域名库剔除 crl.microsoft.com；构建补 zipalign

v2.6
 · 目标 App 包名、上游 DNS 改为可配置（设置页）——不再硬编码任何具体应用
 · 上游 DNS 可换为本地/自建解析器
 · 公开发布准备：LICENSE / README / 第三方署名 / 免责声明

v2.5
 · 授权实证校验：只有"真的能读到该目录"才算已授权（避免显示已授权却删不动）
 · 「清理记录」页新增「取消目录授权」入口

v2.4
 · 权限降级：移除「所有文件访问(MANAGE_EXTERNAL_STORAGE)」，改为 SAF ——
   只授权一个目录（默认 Download），应用就只能碰这一个目录
 · 匹配收窄（防误删）：文件必须"命中广告关键字 且 是广告素材/下载器产物扩展名"
   才删；zip/txt/doc/pdf 一律不碰；目录名必须纯英文（中文名不碰）
 · 全部留痕：每次删除写 deleted.log（时间/类型/大小/完整路径），可随时查
 · 新增「清理前先问我」开关：只列清单，确认后才删

v2.3
 · 新增「广告样本」：清理广告素材前自动留一份图片/视频（最多 24 个 / 48MB），
   可直接看到"原广告长什么样"
 · 新增「标记广告」：拦截详情里点任意一条记录 → 给出人话结论
   （它属于哪个广告体系 + 同一时刻还有哪些域名在活动），可一键
   「标为广告」或「不是广告 → 放行」（加入例外，立即生效）
 · 标记记录留档，方便回看与汇总

v2.2
 · 主界面整页可滚动；显示版本号；新增「更新内容」页

v2.1
 · 内置广告域名库（由 anti-AD 公开列表编译，约 9.9 万条），可一键停用
 · 规则统计分四项显示：域名库 / 手工 / 自加 / 例外

v2.0
 · 修复 rules.txt 中注释行被当作规则计数的 bug

v1.9
 · 新增「只抓目标App」诊断模式：日志里只留目标应用的域名，便于广告溯源

v1.8
 · 清理扩展到公开存储：广告下载器与素材落地的产物可自动清理

v1.7
 · 规则收紧：撤掉可能误伤的宽泛规则，只保留能定位到具体广告 SDK 的域名
 · 新增「例外（放行）」：优先级最高，误伤可即时恢复

v1.6
 · 补齐广告 SDK 组件与跳转链路域名（素材 CDN、上报、HTTPDNS 等）

v1.5
 · 广告缓存清理；跨应用 Android/data 受系统限制，需配合电脑端 adb 脚本

v1.4
 · 新增「拦截规则」界面：加/删域名，改完立即生效，无需重启拦截

v1.0
