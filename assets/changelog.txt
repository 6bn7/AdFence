AdFence 更新内容（倒序）

────────────────────────────
v2.8 —— 依据第二轮安全复审计修复（N-1 ~ N-9）
 · N-1 Service 被系统重建时重新读取用户配置：修掉「进程被省电策略杀掉后，
   用户设置的私有上游 DNS 静默回退到公共 DNS」的隐私回归；同时恢复
   「只抓目标App」「自动清理」「先问后删」「域名库开关」
 · N-2 上游 DNS 只接受 IPv4 字面量（填域名会自递归、拖慢全机 DNS），
   保存时校验并明确提示
 · N-3 失败安全：留副本失败就跳过删除，不再「承诺可找回却永久删除」；
   回收站配额满时自动淘汰最旧的；界面明示「目录删除不可撤销、不进回收站」
 · N-4 CI：加最小权限（contents: read）、去掉 PR 触发、支持 Secrets 持久密钥
 · N-5 留样与回收站改放应用私有目录（原来在外部存储，Android ≤10 其他应用可读）
 · N-6 文档更正：规则仅经 App 界面增删（外部 rules.txt 加载已在 v2.7 移除）
 · N-7 背压时回 SERVFAIL（不再静默丢包）；IDN 查询改为转义记录而非拒绝
 · N-8 日志写入加锁（worker 与域名库载入线程并发调用）
 · N-9 清理轮询 3 秒→30 秒；目录特征判定与授权目录查询加缓存

v2.7 —— 依据安全审计报告修复
 · H-2 DNS 转发改用已连接(connect)的 socket，并校验事务 ID/来源/QR 位，消除全设备 DNS 投毒面
 · H-2/M-4 转发移入线程池异步执行 + 64 并发上限背压；单上游超时 4s→1.5s，不再拖死全设备 DNS
 · H-3 删除更保守：默认「清理前先问我」；移除通用目录名 video-cache；目录前缀匹配必须先有 SDK 特征文件
 · H-3 新增回收站：删除的非媒体文件先进 trash/，24 小时内可找回
 · M-1 DNS 日志改写入应用私有目录，且默认只记被拦域名（全量记录需手动开启）
 · M-2 移除从外部存储加载规则（规则注入面）
 · M-3 留样/回收站文件名做净化 + 路径校验，防路径穿越与配额绕过
 · L-1 规则集合改并发安全；L-2 域名做字符白名单校验（防日志注入）
 · L-3 丢弃含压缩指针或多问题段的畸形查询；L-4 统计表加上限
 · L-5 域名库剔除 crl.microsoft.com；L-6 构建补 zipalign；签名口令不再硬编码

v2.6
 · 目标 App 包名、上游 DNS 改为可配置（设置页）——不再硬编码任何具体 App
 · 追加「上游 DNS」可换成本地/自建解析器
 · 为公开发布做准备：补 LICENSE / README / 第三方署名 / 免责声明

v2.5
 · 授权实证校验：只有"真的能读到该目录"才算已授权（避免显示已授权却删不动）
 · 「清理记录」页新增「取消目录授权」入口
 · 界面文案更正：不再提「所有文件访问」权限

v2.4
 · 权限降级：移除「所有文件访问(MANAGE_EXTERNAL_STORAGE)」，改为 SAF ——
   你只授权一个目录（默认 Download），App 就只能碰这一个目录
 · 匹配收窄（防误删）：文件必须"命中广告关键字 且 是广告素材/下载器产物扩展名"
   才删；zip/txt/doc/pdf 一律不碰；目录名必须纯英文（中文名不碰）
 · 全部留痕：每次删除写 deleted.log（时间/类型/大小/完整路径），
   新增「清理记录 / 标记记录」页可随时查
 · 新增「清理前先问我」开关：只列清单，你确认后才删
v2.3
 · 新增「广告样本」：清理广告缓存前自动留一份图片/视频（最多 24 个 / 48MB），
   直接在 App 里看到"原广告长什么样"
 · 新增「标记广告」：拦截详情里点任意一条记录 → 给出**人话结论**
   （它属于哪个广告体系 + 同一时刻还有哪些域名在活动），可一键
   「标为广告」（保持/加强拦截）或「不是广告 → 放行」（加入例外，立即生效）
 · 标记记录留档：domain-marks.txt / sample-marks.txt，方便以后回看
 · 主界面新增「广告样本（看原广告）」入口
